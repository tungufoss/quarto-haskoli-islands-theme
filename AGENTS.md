# Agent Instructions

This is a public Quarto theme/extension repository. Do not add personal data, private evidence files, academic reporting records, or academic-profile pipeline logic here.

## Boundaries

- Keep Quarto styling, extension metadata, layout components, and examples here.
- Keep academic data-processing logic in the academic-profile package.
- Keep personal website data in private site repositories.
- Examples must use synthetic or public-safe content only.

## Workflow

- Work on branches.
- Do not push feature work directly to `main`.
- Use pull requests and squash merge.
- Delete branches after merge.
- Tag releases for usable theme versions.
- Keep changes small and reviewable.
- Test examples for website, book, and slides when relevant.

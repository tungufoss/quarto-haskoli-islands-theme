# Agent Instructions

This is a public Quarto theme/extension repository for Háskóli Íslands /
University of Iceland style assets. Keep all work self-contained and safe for a
public open-source repository.

## Design Source

The theme is based on the public Háskóli Íslands design standard,
HÖNNUNARSTAÐALL HÍ: <https://honnun.hi.is/>.

Reference and attribute that source clearly. Unless the repository is explicitly
official, do not imply official endorsement by Háskóli Íslands.

## Boundaries

- Keep Quarto styling, extension metadata, layout components, examples, and
  public documentation here.
- Support website, book, and RevealJS slide formats as the extension grows.
- Use synthetic or public-safe example content only.
- Do not add academic-profile data-processing logic.
- Do not add personal academic records, private evidence files, CV source data,
  generated personal site output, or private repository references.
- Do not redistribute third-party brand assets unless their terms clearly allow
  it; note separate terms where relevant.

## Workflow

- Work on branches, not directly on `main`.
- Use pull requests into `main`.
- Use squash merge for completed pull requests.
- Delete merged feature branches.
- Tag releases for usable theme versions.
- Keep changes small and reviewable.
- Render affected Quarto examples for website, book, and slides when relevant.
- Keep README, CONTRIBUTING, LICENSE, and this file consistent when project
  boundaries or release workflow change.

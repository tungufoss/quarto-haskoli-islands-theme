# quarto-haskoli-islands-theme

Reusable Quarto theme and extension for Háskóli Íslands websites, books, and slides.

This is a public presentation/theme repository. It must not contain personal academic data or academic-profile pipeline logic.

## Scope

- Quarto theme assets and extension metadata
- Website, book, and RevealJS slide styling
- Icelandic and English examples/defaults
- Háskóli Íslands colours, typography, layout, and reusable presentation components

## Repository Rules

- Work on branches, not directly on `main` after initial setup.
- Use pull requests and squash merge.
- Tag releases when publishing usable theme versions.
- Keep academic data-processing logic out of this theme.
- Keep personal/private data out of this public repository.
